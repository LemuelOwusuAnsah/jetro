# Jetro · Music Jams Festival

A single-page landing site for a beach music festival in Ghana. Single HTML file, no build step, no framework.

## Live

https://lemuelowusuansah.github.io/jetro/

## Features

- Hero, lineup, workshops, art installations, vendors, and footer sections
- Layered gradients and subtle repeating pattern background
- Google Fonts (Inter, Space Grotesk)
- Responsive card grids
- Fully responsive
- Single-file — entire site in `index.html`

## Notes

- Images are loaded from Unsplash CDN. They may change or break over time; self-host if you fork.
- This is a demo — lineup and vendor details are fictional.

## Run locally

Open `index.html` in a browser. No install, no server.

Or serve it:

    python3 -m http.server 8000

Then open http://localhost:8000.

## Stack

Plain HTML, CSS. No build step, no dependencies.
